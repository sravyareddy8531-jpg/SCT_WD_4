# Task 4 - To-Do Web Application

## 📌 Description
This project is a basic To-Do Web Application developed as part of my internship. It allows users to add, manage, and organize daily tasks with date and time.

## 🚀 Features
- Add new tasks
- Set date and time for tasks
- Mark tasks as completed
- Edit existing tasks
- Delete tasks
- Simple and user-friendly interface

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

## 🎮 How to Use
1. Enter a task in the input box
2. Select date and time
3. Click on "Add" button
4. Click on task to mark as completed
5. Use "Edit" to modify task
6. Use "Delete" to remove task
